🔐 Best practices

  • Storage: Hash keys with SHA-256 before storing; never store plaintext.
  • Rotation: Rotate keys every 90 days (or less for high-security).
  • Scoping: Use separate keys for read-only, write, admin scopes.
  • Prefix conventions: Use prefixes like sk_live_ (secret), pk_test_ (public test) to identify environment & type.
  • Rate limiting: Apply per-key rate limits to reduce abuse.
